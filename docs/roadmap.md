# Roadmap

Orbit is being built in phases. Do not skip ahead inside a phase by simulating its outputs.

| Phase | Scope | Status |
| --- | --- | --- |
| 1 | Users, organizations, projects, lifecycle registry, tenant isolation | This release |
| 2 | Product description, discovery engine, versioned wiki | Not started |
| 3 | Architecture decisions, requirements, task planner, dependency graph | Not started |
| 4 | GitHub integration, repository creation, repository scanner | Not started |
| 5 | Coding agent, tool system, Docker sandbox | Not started |
| 6 | Testing, bounded repair, commits, pull requests | Not started |
| 7 | WebSocket activity, execution logs | Not started |
| 8 | Project memory retrieval, wiki sync, repository intelligence | Not started |

The end-to-end definition of done — describe a product, approve a specification, watch an agent, see a real pull request — is the V1 milestone after these phases. It is not claimed here.

Three different product descriptions can already be registered. They are not implemented. That distinction is the point of the platform.
